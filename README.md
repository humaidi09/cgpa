# CGPA Calculator

A CGPA/GPA calculator web app. Add your courses across semesters and watch your
semester GPA and cumulative CGPA update live, plan the grades you need to reach a
target CGPA, and generate submission-ready assignment cover pages from the
built-in Student Tools. Everything runs in the browser — your data stays on your
device.

**Live demo:** https://humaidi.me/cgpa/

## Features

- Semester GPA and cumulative CGPA computed from your real course data
- Course management across multiple semesters
- Target-CGPA planner — the results you need next to hit a goal
- Insights and an at-a-glance overview of your progress
- **Student Tools → Assignment Cover Page Creator:** fill in your academic
  details, pick a template, preview an A4 page live, and download PDF/PNG or print

## Built with

React 19 · Vite · Tailwind CSS v4 · React Router · Zustand · Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL (the app is served under `/cgpa/`). Build for
production with `npm run build`.
